# Copilot-Assisted Packet Sniffer — Seeing the Network (Ethically)

A small, ethics-guardrailed packet sniffer built for a networking/security lab.
It decodes Ethernet/IP/TCP/UDP, DNS queries, and unencrypted HTTP request
lines, and **redacts sensitive fields before anything is logged or printed**.

## Scope & Ethics (read this first)

This tool may only be used to capture:

- Traffic on **your own machine** or **loopback (`lo`)**, or
- Traffic on an **instructor-provided lab VM/network** that you have explicit
  permission to monitor.

**Do not** point this at shared Wi-Fi, a campus network, a coworker's
machine, or any network you don't own or have written authorization to
test. Capturing traffic you're not authorized to see is illegal in most
jurisdictions (e.g., wiretapping / computer-misuse statutes) even if it's
technically easy.

The tool enforces part of this itself:

- **Interface allowlist**: live capture only works on `lo` / loopback
  (or an interface an instructor adds to `ALLOWED_IFACES` in `sniffer.py`).
  Anything else raises `PermissionError` and refuses to run.
- **pcap-first default**: if you don't have capture privileges (or just
  want a safe, reproducible mode), read from a `.pcap` file instead —
  no root/CAP_NET_RAW needed.
- **Redaction before output**: IPs are partially masked, and anything that
  looks like an email, a cookie, an `Authorization` header, or a
  `password=` / `token=` style query parameter is redacted before it's
  printed or written to a log.

## Setup

Requires Python 3.10+ and a Linux environment (Ubuntu/Kali VM, or WSL2 +
a Linux VM if you're on Windows).

```bash
python3 -m venv venv
source venv/bin/activate
pip install scapy pytest
```

Live capture on Linux needs raw-socket privileges:

```bash
sudo setcap cap_net_raw,cap_net_admin=eip $(readlink -f $(which python3))
# or simply run with sudo — but prefer pcap mode where possible
```

If you don't have (or don't want to grant) those privileges, use `--pcap`
mode — it's the default recommendation and requires no special permissions.

## Regenerating the sample lab traffic

`sample_pcaps/lab_traffic.pcap` is a small synthetic capture (DNS query +
two HTTP requests) built entirely in-memory with scapy — no live capture
or network access involved. Regenerate it any time with:

```bash
python3 tests/make_sample_pcap.py
```

In a real lab, replace this with actual traffic generated by the
instructor-provided "victim service" (a local web server + a few DNS
lookups) that you sniff on `lo`.

## Run examples

**Safe default — analyze a pcap file:**

```bash
python3 sniffer.py --pcap sample_pcaps/lab_traffic.pcap
```

**Write redacted JSON-lines output to a file:**

```bash
python3 sniffer.py --pcap sample_pcaps/lab_traffic.pcap --out capture.log.jsonl
```

**Live capture on loopback only, with a BPF filter, capped at 25 packets:**

```bash
python3 sniffer.py --iface lo --count 25 --filter "tcp port 80 or udp port 53"
```

**Attempting to sniff a non-allowlisted interface is refused:**

```bash
$ python3 sniffer.py --iface eth0
[BLOCKED] Refusing to sniff on 'eth0': not in ALLOWED_IFACES ['Loopback', 'Loopback Pseudo-Interface 1', 'lo', 'lo0']. ...
```

## Running the tests

```bash
python3 -m pytest tests/ -v
```

25 unit tests cover: IP masking, email/cookie/token/Authorization
redaction, the interface allowlist, and end-to-end decoding of the sample
pcap (DNS query, HTTP GET, HTTP POST).

## AI Use Policy (Copilot)

This project was built with GitHub Copilot assistance under the following
rules:

**Use Copilot for:**
- Boilerplate (argparse setup, dataclasses, JSON formatting)
- Unit test scaffolds
- Regex drafts for redaction patterns (then manually reviewed/tightened)

**Do NOT ask Copilot for:**
- Capturing traffic belonging to other people or networks you don't own
- Bypassing OS permission checks (e.g., "how do I sniff without root")
- Stealth features, persistence, hiding the tool's activity, or evading
  detection — this is a visible, auditable lab tool, not something meant
  to hide

**Always:**
- Keep the interface allowlist (`ALLOWED_IFACES`) in place and reviewed —
  never widen it to `"*"` or remove the check
- Keep redaction (`redact_text` / `mask_ip`) applied to every output path,
  including any new log format someone adds later
- Default to pcap mode when live-capture privileges are missing, rather
  than suggesting privilege escalation

### What Copilot suggested that was rejected/modified 
-Improve HTTP detection: parse more request shapes than just payloads starting with “GET ” / “POST ”, because real traffic often has extra bytes, fragmented TCP payloads, or different casing. It would be more resilient to parse headers before deciding the packet is HTTP.

-Harden the interface allowlist: normalize names case-insensitively and centralize the validation so aliases like “Lo” or “Loopback 1” are handled consistently. This is the biggest security boundary in the project.

- Redact more aggressively in the parsed record, not only in the final JSON: ensure any future summary/debug fields cannot accidentally leak secrets, even if they are added later.
